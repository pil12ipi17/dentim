# Android Караоке - Обработка Дубликатов 🔄

## Как работает обнаружение дубликатов?

### 1. 📋 **Процесс проверки**
При загрузке файла приложение выполняет следующие шаги:

1. **Извлечение метаданных** - получает информацию о файле
2. **Вычисление MD5** - создает уникальный отпечаток файла  
3. **Проверка дубликатов** - ищет в базе файл с таким же MD5
4. **Показ диалога** - если дубликат найден

### 2. 🔍 **Алгоритм обнаружения**

```kotlin
// Шаг 1: MD5 чексумма файла
val checksum = ChecksumCalculator.calculateMD5(file)

// Шаг 2: Поиск в базе данных
val existingTrack = trackRepository.getTrackByChecksum(checksum)

// Шаг 3: Если найден - показываем диалог
if (existingTrack != null) {
    emit(UploadProgress.DuplicateFound(existingTrack))
}
```

### 3. 💬 **Диалог дубликата**

Когда дубликат найден, появляется диалог:

**"Duplicate Track Found"**
> Найден трек с таким же содержимым: `имя_файла.mp3`
> 
> Хотите загрузить в любом случае?

**Варианты:**
- ✅ **"Upload Anyway"** - загружает повторно  
- ❌ **"Cancel"** - отменяет загрузку

### 4. 🎯 **Что делать при дубликате?**

#### Вариант А: Cancel (Рекомендуется)
- Файл уже есть в системе
- Не тратит место и время на обработку  
- Можете найти его в списке треков

#### Вариант Б: Upload Anyway 
- Создаст второй экземпляр того же файла
- Полезно для тестирования разных настроек ИИ
- Займет дополнительное место

### 5. 🔧 **Технические детали**

#### MD5 чексумма:
- **32 символа** - точный отпечаток файла
- **Идентична для идентичных файлов** - даже с разными именами
- **Различается при любом изменении** - даже на 1 байт

#### Быстрая проверка:
```kotlin
// Первичная проверка по размеру и началу/концу файла
val quickChecksum = ChecksumCalculator.calculateQuickChecksum(file)
```

#### Полная проверка:
```kotlin
// Точная MD5 всего файла
val fullChecksum = ChecksumCalculator.calculateMD5(file)
```

### 6. 📊 **Пример работы**

1. **Первая загрузка** `song.mp3` (MD5: abc123...)
   - ✅ Файл сохранен
   - ✅ Запущена обработка

2. **Повторная загрузка** того же `song.mp3` 
   - 🔍 MD5: abc123... (совпадает!)
   - ⚠️ Показан диалог дубликата
   - 👤 Пользователь выбирает: Cancel или Upload Anyway

3. **Переименованный файл** `my_song.mp3` (то же содержимое)
   - 🔍 MD5: abc123... (все равно совпадает!)  
   - ⚠️ Дубликат обнаружен по содержимому
